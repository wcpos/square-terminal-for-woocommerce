# Square Terminal for WooCommerce 0.8.6

Completes a Square Terminal payment exactly once. Before this release an order could be marked paid twice, which reduced its stock twice.

## Fixed

- **An order could be completed twice, reducing stock twice.** The Square webhook, the payment screen's status check, the background sweep and the Square POS app return can all complete a paid checkout. Each one waits its turn on a per-order lock and then re-reads the order. That re-read returned the copy the request had loaded before it waited, so a request that waited while another one completed the order still saw it unpaid. It completed the order again, and WooCommerce reduced stock, sent its paid-order hooks and recorded the payment a second time. Inside the lock, the order is now read with the post and HPOS order caches cleared and its meta read again from the database, so the request that waited sees the paid order and its recorded payment and leaves it alone.

## Upgrade

No configuration changes are required. Orders that were already completed twice keep their stock levels; check recent Square Terminal orders against your stock if you saw unexpected drops.
