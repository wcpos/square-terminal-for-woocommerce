# Square Terminal for WooCommerce 1.0.0

This is the version of Square Terminal for WooCommerce for WCPOS 2.0. It needs WooCommerce POS Pro 2.0.0 or later. Without it, the plugin shows an admin notice and does nothing else. The gateway is now for staff on the POS only, and is never offered on your shop's checkout.

## Changed

- **WooCommerce POS Pro 2.0 is required.** Without a compatible Pro, the plugin shows an admin notice and registers no gateway, webhook or background check.
- **The gateway is POS-only.** It is offered on the POS, and on the order-pay page to staff who may use the POS. It is never offered on the shop's checkout. Switch it on in POS → Settings → Checkout. The "Enable Square Terminal for web checkout" setting is gone, and a value saved for it before the upgrade has no effect.
- **Payments on a paired Square Terminal run through WCPOS Pro 2.0.** The POS sends the checkout to the Terminal, follows it, can cancel it, and records Square's answer.
- **Refunds go through Square.** A refund of a Terminal payment is sent to Square. If Square does not answer, the plugin asks again for the same refund, so a lost answer cannot cause a second refund. It keeps asking until Square confirms the refund or staff are told to check the Square dashboard.
- **Checkouts started before the upgrade are carried over.** A Terminal checkout still open on an unpaid order is taken over by WCPOS Pro on upgrade.
- **Square Reader keeps its own payment screen.** If you chose Square Reader under "Which Square device do you use?", the hand-off to the Square Point of Sale app still uses this plugin's own payment screen. A Square Point of Sale payment that comes back for an order that was already paid adds a note to the order, so you can check the Square dashboard for a second charge.

## Upgrade

Make sure WooCommerce POS Pro 2.0.0 or later is active. If you took Square Terminal payments on the shop's checkout before, that is no longer possible: switch the gateway on for the POS in POS → Settings → Checkout.

The full list of changes is in `CHANGELOG.md` under 1.0.0-beta1.
