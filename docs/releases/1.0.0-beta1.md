# Square Terminal for WooCommerce 1.0.0-beta1

First beta of 1.0.0, for the WCPOS 2.0 beta. A prerelease: install the zip by hand on a test store.

The extension now runs on WCPOS Pro 2.0's shared payments base and requires WCPOS Pro 2.0.0 or later. Without a compatible Pro it shows an admin notice and registers nothing.

## Changed

- **A server adapter for the WCPOS Pro 2.0 payments base.** The POS app drives a paired Square Terminal through Pro's ledger: checkout, polling, cancellation, signed webhooks on Pro's route, and refunds through Square's Refunds API.
- **The POS order-pay page runs through WCPOS Pro's shared panel** when the collection method is a paired Terminal. Checkouts the old panel left live are adopted into Pro's ledger on upgrade. The Square Point of Sale app hand-off keeps the plugin's own panel.
- **The gateway is POS-only.** It is never offered on the shop's checkout; the "Enable Square Terminal for web checkout" setting is gone.

The full list is in `CHANGELOG.md` under 1.0.0-beta1.
