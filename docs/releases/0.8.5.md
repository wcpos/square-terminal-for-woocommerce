# Square Terminal for WooCommerce 0.8.5

Gives the gateway a name everywhere WooCommerce shows one. It appeared as a blank row in the WooCommerce POS checkout gateway list and reported a null title through the WooCommerce REST API.

## Fixed

- **The gateway had no title outside the WooCommerce Payments screen.** The gateway set only its admin `method_title` and never the public `title` and `description` properties that WooCommerce reads for `get_title()`, the REST API, order payment-method titles and the WooCommerce POS gateway list. The Payments screen falls back to `method_title`, so the gateway looked fine there while showing up in POS → Settings → Checkout as an unnamed row with only the ID `sqtwc`, easy to miss in a long list. Both properties are now set from the method title and description.

## Upgrade

No configuration changes are required. The row in POS → Settings → Checkout is named "Square Terminal" after updating. It keeps whatever position and enabled state it already had.
